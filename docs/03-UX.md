# 03 · UX структура и design system

## Основен flow

Регистрация → (кратък onboarding, 3 стъпки) → Dashboard → **Качи PDF** → обработка (реален прогрес) → **Провери резултатите** → Потвърди → „Изследването е добавено към твоята здравна история.“ → Показател → Графика → Сравни → Добави специалист → Генерирай обобщение.

## Навигация

| Desktop (sidebar) | Mobile (bottom nav) |
|---|---|
| Начало · Изследвания · Показатели · Графики · Хронология · Документи · Специалисти · Профил · **[Качи изследване]** | **Начало · Изследвания · [＋ Качи] · Показатели · Профил** |

На mobile „Документи“, „Специалисти“, „Хронология“, „Графики“ са достъпни от Начало (quick actions) и от Профил. Бутонът „Качи“ е централен в bottom nav → достъпен от всеки основен екран. Глобално търсене: иконка в header (⌘K / Ctrl+K на desktop).

## Език (правила)

| Вместо | Пишем |
|---|---|
| „Опасно високо“ | „↑ Над референтния диапазон на лабораторията“ |
| „Здравето ти се влошава“ | „Стойността се е увеличила с 12% спрямо предходното измерване.“ |
| „Нормално“ | „✓ В референтния диапазон“ |
| „AI анализ“ | „Автоматично извлечено · провери“ |

Тенденция: ↑ Повишава се / ↓ Намалява / → Стабилна (|Δ| < 3% от предходната) – чисто числово, без оценка. *Прагът от 3% е UX конвенция за „стабилна“, не медицинско правило* – отбелязан е в кода.

## Design system „Vitalog Calm“

- **Цветове**: бяло/`#F6F7F8` фон, графит `#1E2329` текст, акцент *Sea glass* (тюркоазено-зелен `#0E7C74` light / `#5CC8BC` dark). Статуси: в диапазон – акцент; извън диапазон – топъл кехлибар `#B45309` (не червено); червено само за системни грешки. Всеки статус = цвят + икона + текст.
- **Типография**: Manrope (заглавия, цифри в cards) + Inter (текст, таблици, `tabular-nums`). И двата с пълна кирилица, self-hosted. Минимален размер 14px (13px само за мета етикети), body 16px.
- **Подпис на идентичността**: *range bar* – тънка писта с референтна зона и точка, използва се в cards, таблици, профил.
- **Форма**: радиус 16px за cards, 12px за контроли; touch targets ≥ 44px; меки сенки само в light mode.
- **Движение**: 150–250ms transitions, `prefers-reduced-motion` спира анимациите.
- **Dark mode**: system / light / dark, пази се в профила и localStorage.

## Достъпност (WCAG 2.2 AA)

Skip link, landmarks, видим focus ring, клавиатурна навигация навсякъде (включително точките на графиката чрез табличния изглед), `aria-live` за прогреса на обработката, ARIA labels на icon бутони, контраст ≥ 4.5:1, графика + таблица, статусите никога само с цвят.
